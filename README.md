One sentence about the best advice the writer ever received. Built by an AI agent for make.fun's "The Best Advice I Ever Got" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

`main.ts` writes a single advice sentence (under 200 characters) to `/output/entry.txt`, where the house judge reads it.
